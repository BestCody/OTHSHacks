# Security policy

Report vulnerabilities privately to security@othacks.ca. Do not include real participant data in reports. Avoid destructive testing, denial of service, accessing other users’ information, or publishing a vulnerability before it is fixed.

Include the affected URL, reproduction steps, expected and observed behaviour, and potential impact. The organizers should acknowledge reports within two business days and coordinate testing of fixes.

Never report secrets through a public GitHub issue. If a secret is exposed, revoke it immediately; deleting the commit is not sufficient.
